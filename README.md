Unknown Client

A custom Fabric client for Minecraft Java 26.3, with its own launcher and installer.

Features

New look: an animated black hole main menu, a starfield background, and restyled buttons, pause menu and loading screens
Click menu: windows or wheel layout, animated switches, search, and a theme builder
HUD: FPS, coordinates, direction, clock, biome, ping, keystrokes, CPS and more. Drag items to move them, and right-click to resize or recolour.
Performance: profiles for different computers, and particle and effect settings
Tools: waypoints, a custom crosshair, zoom, and import or export of your settings
Badge: an icon next to other Unknown Client players’ names, which you can turn off

Launcher: add mods from Modrinth or by drag-and-drop, saved instances, crash reports, and automatic updates.

Install: download UnknownClient-Setup.exe from the latest release, run it, and press Play. It needs no admin rights. If Windows warns you, click More info, then Run anyway.

Fan project, not connected to Mojang or Microsoft.
